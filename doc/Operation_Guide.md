# ESP32 Sorter 操作指南

本指南说明如何操作分拣系统。**当前系统硬件配置仅包含 RS485 触摸屏作为唯一人机交互设备（OLED 显示器、物理旋钮编码器及其他屏幕全部不支持）**，全面采用基于电磁铁的出口分拣逻辑。

---

## 1. 系统主模式与页面导航

系统通过 **RS485 触摸屏** 进行页面直接切换与参数控制（不支持 OLED 与旋转编码器导航）。

### 1.1 正常生产模式 (Dashboard)
用于实时生产分拣。
-   **Dashboard (仪表盘)**：实时显示当前分拣速率（根/秒、根/小时）、识别物体累计数量。
-   **实时直径**：显示扫描仪检测到的最新物体直径（单位：mm）。

### 1.2 硬件诊断页面 (Hardware Diagnostics)
通过 RS485 触摸屏切换到对应诊断页面，可对硬件进行独立测试：
-   **编码器诊断 (`diag_encoder`)**：展示传送带编码器的原始脉冲、校正值、逻辑位置（0-199）、Z相清零计数及零位偏移量（支持远程设置偏移 `set_offset`）。
-   **激光扫描仪诊断 (`diag_laser`)**：查看 4 路激光传感器的即时遮挡电平状态、采样点数及历史波形点阵。
-   **分拣出口诊断 (`diag_outlets`)**：支持在触摸屏上手动点击独立控制各个出口电磁铁的开合状态（`diag_outlet`），或观察各出口实时状态。

### 1.3 常规配置 (`config_outlets`)
-   **出口参数配置**：通过 RS485 触摸屏直接配置各出口对应的最小直径（Min）、最大直径（Max）及长度等级掩码（S/M/L），下发 `set_outlet` 指令后自动保存至 EEPROM。

### 1.4 版本信息 (`about`)
-   显示当前固件版本信息及系统启动计数。

---

## 2. HMI 与物理控制

### 2.1 交互逻辑（仅 RS485 触摸屏）
-   **页面同步 (`page_sync`)**：在 RS485 触摸屏上切换页面时，主控自动同步切换对应的业务模式（App）。
-   **触控指令下发**：触摸屏通过 RS485 JSON 帧协议直接下发出口配置（`set_outlet`）、出口手动测试（`diag_outlet`）、相位偏移校准（`set_offset`）和清零（`tare`）等指令。
-   *注：系统不再支持 OLED 屏幕、物理旋钮旋转及实体按键操作。*

### 2.2 出口执行器 (Electromagnet Outlets)
-   分拣出口由 **H桥** 驱动的电磁铁组成。
-   由状态机控制 `OPEN` 或 `CLOSE` 脉冲（非持续供电，防止烧毁线圈）。

### 2.3 RS485 触摸屏显示
-   自研 LVGL RS485 串口触摸屏提供所有工作模式的数据可视化与触控交互。
-   **刷新策略**：主控以快照（`DisplaySnapshot`）机制按当前激活页面构建 JSON 数据帧并通过 RS485 推送至触摸屏。

### 2.4 指示灯 (LED)
-   级联移位寄存器 (74HC595) 输出，反映出口当前的物理开合位置状态。
